# Backlog do dashboard no GitHub

## Escopo e uso

Este documento localiza as entregas publicadas a partir de Q1–Q37 e do
[plano consolidado](dashboard-implementation-plan.md). As issues contêm
contexto, objetivo, orientações, fora de escopo, dependências, fontes, cenários
mínimos de teste, critérios de aceite e evidência necessária para encerramento.
O GitHub é a fonte do estado de execução; este mapa não declara funcionalidades
implementadas nem autorização de operação remota.

[Issue central #127](https://github.com/ThiagoCrepequer/holon/issues/127) acompanha **40 entregas MVP**
como sub-issues nativas. Há **42 issues** no total: 40 entregas, o tracker e
uma evolução para SSE fora do MVP. O [PR documental](https://github.com/ThiagoCrepequer/holon/pull/126)
publicou as referências no commit `e57129fcbe64e36ed8f05a5d4efae051f9a0e87f`.
Os links das issues usam esse SHA para preservar a fonte durante evoluções posteriores.

A [base documental #128](https://github.com/ThiagoCrepequer/holon/issues/128) foi encerrada
com o merge e a CI do PR documental. As funcionalidades do dashboard
não foram implementadas por essa publicação. A execução local do milestone 0
está nos [resultados das provas](../research/2026-10-05-dashboard-milestone-zero-results.md):
DASH-02 agora comprova recuperação por linking nativo com email verificado
aprovado em 2026-10-05 e não reutilização concorrente de code com o
[plugin público aprovado](../research/2026-10-05-dashboard-code-redemption-plugin.md).
DASH-02 tem GO local nos dois adapters; as quatro provas de viabilidade
integram o gate geral. O GitHub conserva o estado de revisão/merge e
encerramento; não confundir prova M0 com auth produtiva.

Nenhum prazo ou responsável individual foi inventado. A publicação deste
backlog não criou recursos, secrets, DNS, migrations remotas nem deploys.
Operações posteriores estão no [runbook](../operations/dashboard-environments-and-recovery.md),
com autorização e evidência datadas. ADRs aceitos continuam
prevalecendo; novos ADRs e as provas técnicas são entregas iniciais. Um no-go
de candidato não é conclusão bem-sucedida da integração e bloqueia dependentes.

## Qualidade e conclusão

O MVP reduz funcionalidades; não reduz segurança, recuperação, usabilidade,
performance nem testes dos fluxos incluídos. Cada issue define comportamento
permitido/negado, falhas e concorrência relevantes. Preservar os thresholds
por suite da [política de testes](../engineering/testing-and-evidence.md),
sem excluir produção ou mascarar falha pela repetição. Prosa não exige teste
artificial e teste local não comprova integração real.

Fechar o tracker exige as 40 entregas MVP, matriz ampla pt-BR/en nos três engines,
budgets e ensaios de recuperação, nenhum gate impeditivo aberto e publicação/
smokes reais autorizados do mesmo artefato. SSE não é filho do tracker, não
bloqueia promoção e não permite polling no MVP. Billing, analytics, novos
providers, edição/rerun de review, exclusão/transferência e opções do radar
permanecem fora deste escopo.

A automação em Chromium/Firefox/WebKit não comprova sozinha a matriz de suporte
Q3: duas versões estáveis mais recentes de Chrome/Edge, Firefox e Safari,
Safari iOS e Chrome Android. A issue de qualidade exige evidência complementar
com versões, aparelhos, entradas e data identificados.

## Conferência da publicação

Em **2026-10-04**, a leitura das APIs do GitHub confirmou os títulos/corpos,
labels e milestones das 42 issues, os oito milestones sem datas inventadas,
as 40 sub-issues MVP e **130 bloqueios nativos**. A conferência
comparou o conteúdo remoto com o manifesto preparado; não executou as tarefas
nem comprovou CI, OAuth, D1/Queues ou entrega real de email.

Os contadores agregados REST do milestone 1 retornaram 4 abertas/0 fechadas,
enquanto a coleção de issues por estado no GraphQL retornou 3 abertas/1 fechada,
coerente com a associação e o estado individual conferidos. A validação usa
estas fontes individuais e a coleção por estado; não alterou recursos para
forçar o contador agregado nem atribuiu uma causa não comprovada à divergência.
