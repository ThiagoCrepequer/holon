# Arquivo de explorações

Estas propostas foram criadas em 2026-10-04 e preservadas para reaproveitamento
futuro. **Não são alternativas ativas da marca.** A identidade atual usa a
Semente da primeira rodada; seus arquivos oficiais estão em
[`../assets/logo/`](../assets/logo/).

| Rodada                                     | Conteúdo                                                |
| ------------------------------------------ | ------------------------------------------------------- |
| [Inicial](2026-10-04-initial/index.html)   | Órbita, Encaixe, Molduras, ὅλον, Rastro e Semente       |
| [Abstrata](2026-10-04-abstract/index.html) | Eco, Laço, Gérmen, Mosaico, Espiral, Dobra, Elo e Razão |

A rodada inicial também guarda os SVGs de uma variante preliminar chamada
Recursão, que foi substituída por Semente antes da prancha final. Gérmen é a
evolução recursiva apresentada na segunda rodada e não substitui a Semente
escolhida.

Cada pasta preserva símbolos, assinaturas quando existentes, prancha, HTML
de apresentação e script de geração. Fontes das explorações podem depender
do sistema operacional; esse limite não se aplica às assinaturas oficiais
atuais convertidas em contornos.

Reutilizar um estudo significa criar uma aplicação nova e documentar a escolha,
sem apontar produtos ativos diretamente para os arquivos históricos. O arquivo
não inclui as imagens de referência externas, que serviram como inspiração.
